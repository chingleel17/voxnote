# 設計：YouTube 影片字幕與內嵌播放

## 處理與播放流程

```text
使用者貼上 YouTube URL
  → 驗證來源、影片類型與可存取性
  → yt-dlp 取得音訊及影片 ID／標題（不下載視訊）
  → 批次 ASR 完成整支轉錄
  → 以分段 start/end 組裝字幕時間軸
  → 儲存影片項目
  → 開啟 VoxNote 獨立播放視窗
  → YouTube IFrame Player API 播放影片
  → 以 player.getCurrentTime() 選取當下字幕
```

字幕產生與播放彼此分離。處理期間不需播放影片；重新開啟已處理項目時直接使用既有時間軸，不重新轉錄。

## 獨立播放視窗

播放視窗載入 VoxNote 隨應用程式打包的本地頁面，而不是直接將整個 YouTube 網站設為 Tauri WebView URL。本地頁面內嵌 YouTube 官方播放器，並由 VoxNote 自己繪製字幕層。

這個邊界有三個目的：

- 透過官方播放器 API 取得 `getCurrentTime()`、播放狀態與錯誤事件。
- 避免嘗試跨來源讀取任意 YouTube 網頁的 DOM 或播放器內部狀態。
- 不讓遠端頁面取得 Tauri IPC、檔案系統或其他應用程式權限。

播放視窗應使用獨立 label 與最小 capability。YouTube iframe 不得被授予 Tauri commands；若平台無法區分 iframe 與主頁面的權限邊界，該播放頁面不得持有非必要的敏感權限。

## 字幕同步

播放器時間是唯一真實來源：

```text
currentTime
  → 尋找 start <= currentTime < end 的分段
  → 顯示該段文字
  → 無符合分段時清空字幕
```

同步迴圈只讀取播放器時間，不累加本機 elapsed time。因此下列狀態不需要額外對齊邏輯：

- 暫停：`currentTime` 不前進，字幕維持或依介面決策顯示當下段落。
- 緩衝：播放器時間停止，字幕不會自行超前。
- 跳轉：下一次讀取時間後直接選取新位置的字幕。
- 倍速播放：字幕仍依媒體時間同步，不依牆鐘時間推進。

字幕查找使用分段級時間軸，不宣稱逐字級對齊。實作可依資料量選擇線性游標或二分搜尋，但這屬實作細節。

## YouTube 來源邊界

第一版只接受可解析為單一影片 ID 的 YouTube URL。播放清單 URL 可取出其當下指定的單一影片，但不建立整份播放清單的批次處理。非 YouTube URL、直播與預定直播均於下載前拒絕。

`yt-dlp` 負責音訊與中繼資料取得；YouTube IFrame Player API 負責播放。兩者能力不同：音訊可取得不代表影片允許嵌入，因此必須分別處理擷取失敗與播放器錯誤。

### 無法內嵌

影片禁止嵌入、被移除、設為私人或播放器載入失敗時：

1. 播放視窗顯示可理解的原因。
2. 提供以系統預設瀏覽器開啟原始 URL 的按鈕。
3. 明確說明外部瀏覽器不提供 VoxNote 字幕同步。

不退回浮動字幕或手動對齊模式，避免維護第二套不可靠的同步機制。

## 客戶端是否需要 ffmpeg

既有轉錄服務收到音訊後會自行解碼與前處理。客戶端先直接上傳 `yt-dlp` 取得的相容音訊格式；只有實測證明服務端無法解碼時，才加入 ffmpeg sidecar。這項結論必須於實作前記錄，以免無必要地增加安裝體積與打包工作。

## 資料模型

影片項目與會議記錄分離，至少保存：

- ID（UUID v4）
- YouTube 原始 URL 與影片 ID
- 標題
- 完整逐字稿
- JSON 字幕時間軸
- 建立與更新時間

影片沒有與會人員或語者分離語意，不進入會議清單。

### 摘要歸屬

既有 `summaries` 表以 FK 指向 `meetings`，不能直接保存影片摘要。採用影片專屬摘要表，保留 provider、內容與更新時間等中繼資料，FK 指向影片項目。這避免修改既有會議摘要 schema 與查詢路徑；LLM 呼叫邏輯仍重用既有實作。

## 錯誤與清理

- URL 不支援、直播、需登入、私人影片、地區限制與音訊擷取失敗須分別回報可理解訊息。
- 處理成功、失敗或取消後均清除暫存音訊。
- 播放視窗關閉不刪除已儲存項目，也不影響轉錄任務。
- 同一已儲存項目可重複開啟；若同 label 視窗已存在，應聚焦既有視窗而非建立重複實體。

## 風險

| 風險 | 影響 | 對策 |
|---|---|---|
| YouTube 或 `yt-dlp` 改版 | 音訊取得失敗 | sidecar 可獨立更新；呈現明確錯誤 |
| 影片禁止 iframe 嵌入 | 無法在 VoxNote 播放 | 告知原因並提供預設瀏覽器開啟 |
| WebView 媒體能力或 Referer／origin 不符 | 播放器載入失敗 | 前置實測正式打包環境及各目標平台 |
| 遠端內容取得過多 Tauri 權限 | 本機能力遭濫用 | 本地播放頁最小 capability，不授權 iframe IPC |
| 長影片轉錄逾時 | 處理中斷 | 沿用非同步批次佇列與進度回報 |

## 明確不做

- 不支援非 YouTube 平台。
- 不支援直播或預定直播。
- 不做播放清單批次處理。
- 不做外部瀏覽器同步、瀏覽器選擇或行程音訊對齊。
- 不做浮動字幕與手動對齊。
- 不做逐字 highlight、字幕翻譯或 SRT／VTT 匯出。
- 不下載或保存影片視訊檔。
